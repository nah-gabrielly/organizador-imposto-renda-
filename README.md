# organizador-imposto-renda-
Sobre o projeto

A planilha funciona como um agregador de informações, permitindo reunir dados do titular, informes bancários e registros de entradas financeiras em um único arquivo.

Funcionalidades
Dados do Titular

A aba TITULAR permite registrar informações pessoais, como:

Nome;
CPF;
Data de nascimento;
Título de eleitor;
Cônjuge;
Endereço;
CEP;
Telefone e celular;
E-mail;
Informações relacionadas à declaração anterior;
Dependente cônjuge;
Residência no exterior.
Informes de Rendimentos Bancários

A aba INFORMES permite organizar informações de diferentes instituições bancárias.

É possível registrar:

Banco;
Valor atual;
Anexo relacionado ao informe.

A planilha também possui uma fórmula para realizar a soma dos valores informados nos bancos cadastrados.

Registro de Entradas

A aba NOTAS permite registrar as entradas financeiras ao longo dos meses.

Os registros possuem campos para:

Data;
Categoria;
Valor.

Também existe um campo para acompanhar o total das entradas registradas.

Lista de Bancos

A aba Planilha2 contém uma lista de instituições bancárias que serve como base de apoio para o preenchimento das informações.

Recursos utilizados

Durante a construção da ferramenta foram utilizados recursos do Microsoft Excel, como:

Formatação de células;
Fórmulas;
Organização de dados em diferentes abas;
Listas de apoio;
Campos para entrada de informações;
Validação e organização dos dados;
Referências entre células.

O desenvolvimento deste projeto possibilitou colocar em prática conhecimentos relacionados à organização e manipulação de dados no Excel, além de trabalhar com a criação de uma ferramenta voltada para uma situação prática.

Também foi possível praticar a documentação de um projeto e sua publicação utilizando o GitHub.

Como utilizar
Faça o download da planilha.
Abra o arquivo no Microsoft Excel.
Preencha os dados do titular na aba TITULAR.
Adicione os informes dos bancos na aba INFORMES.
Registre as entradas financeiras na aba NOTAS.
Utilize a lista disponível na aba Planilha2 como apoio para selecionar os bancos.
Confira os valores calculados automaticamente pelas fórmulas.
